# Earlier edition (kept on purpose)

This is the earlier CV and cover-letter suite of the owner, moved here unchanged
from the CareerVector TUI repository folder (`applications/cvl`) on 2026-11-25,
by the owner's decision ("Keep as edition in cvst").

It is **not** a catalogued style: it has no `contract.toml`, so `catalogue()`
does not list it, and nothing renders from it. It is an archive and example
of the older, single-file lineage that Harvard grew out of, with its own CV
wording, the 2-, 3- and 4-page variants (`cv-pages` input), de-ch and en-ch,
and the cover letters.

- `cv/`, `cl/`: sources (`main.typ`) and the checked-in PDF outputs.
- `shared/`: the document style, header component, profile and opportunity data.
- `SUITE.md`: the original README of the suite.

The tree keeps its original layout, so it compiles with this directory as the
Typst root and an `Archivo` font available.
