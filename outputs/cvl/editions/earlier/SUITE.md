# CV and cover-letter suite

This suite contains two document projects and their shared presentation layer:

- `cv/`: German and English CV sources plus two-, three-, and four-page outputs.
- `cl/`: German and English cover-letter sources, the signature asset, and outputs.
- `shared/`: one font set, document styles, components, and canonical profile data.

Both projects compile with this directory as the Typst root and do not depend on machine-installed
fonts. Run their build and watch recipes from the repository root.
